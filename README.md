# Car Switcher

Плавающая кнопка для Android-магнитолы (вертикальный экран 10").

- **Одно нажатие**: список запущенных приложений крупными плитками (3 в ряд), нажатие на плитку переключает.
- **Двойное нажатие**: полноэкранное окно «Закрыть?» с кнопками **ДА / НЕТ** на пол-экрана каждая. «ДА» полностью останавливает текущее приложение.
- Кнопку можно перетаскивать, она прилипает к ближнему краю. Размер: малая / средняя / большая.
- Окна сами закрываются, если ничего не нажать (список: 20 с, подтверждение: 12 с).
- Служба стартует сама после перезагрузки магнитолы.

## Как получить APK (без Android Studio)

1. Создайте репозиторий на GitHub (можно приватный) и загрузите в него содержимое этой папки
   (через «Add file → Upload files» в браузере или `git push`).
2. Откройте вкладку **Actions**: сборка «Build APK» запустится сама (2-4 минуты).
3. Откройте завершённую сборку → внизу раздел **Artifacts** → скачайте `CarSwitcher-apk.zip`, внутри `app-release.apk`.

Либо: установите Android Studio, откройте папку, **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Установка на магнитолу

1. Скопируйте APK на флешку, установите (разрешите «Неизвестные источники», если спросит).
2. Откройте Car Switcher и включите по очереди:
   1. **Показ поверх других приложений**
   2. **Службу специальных возможностей** (Настройки → Спец. возможности → Car Switcher)
   3. *(необязательно)* **Доступ к статистике использования**: тогда в списке будут и приложения, открытые до включения службы.
3. Кнопка появится на экране.

## Как работает закрытие

- Если на магнитоле есть root: `am force-stop <пакет>` (мгновенно).
- Если root нет: приложение само открывает экран «О приложении» и нажимает «Остановить» → «ОК», затем уходит на главный экран. Занимает 1-2 секунды. Кнопка ищется по id и по тексту (EN / RU / AZ / TR), так что работает на большинстве прошивок.

## Структура

```
app/src/main/java/az/anar/carswitcher/
  CarAccessibilityService.kt  служба: кнопка, отслеживание текущего приложения
  OverlayController.kt        плавающая кнопка, список приложений, окно «Закрыть?»
  ForceStopper.kt             остановка приложения (root или через настройки)
  AppTracker.kt               список недавних приложений (LRU + UsageStats)
  MainActivity.kt             экран настройки разрешений и размера кнопки
```

Без сторонних библиотек: только Android SDK и Kotlin. minSdk 24 (Android 7.0), targetSdk 34.
